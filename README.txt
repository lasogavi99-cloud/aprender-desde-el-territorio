APRENDER DESDE EL TERRITORIO — REEMPLAZO DE LA APLICACIÓN

Archivos incluidos:
- src/App.tsx
- src/App.css

Instalación:
1. Haz una copia de seguridad de tus archivos actuales.
2. Reemplaza src/App.tsx y src/App.css por los de esta carpeta.
3. Verifica que src/main.tsx importe App desde './App'.
4. Ejecuta npm run dev.

No requiere paquetes adicionales. La tipografía se carga desde Google Fonts y tiene fuentes de respaldo.

Notas del prototipo:
- El planeador guarda las actividades en localStorage con la clave territorio-plan.
- La biblioteca contiene tres actividades de ejemplo, no material validado del manual.
- Los ocho módulos presentan enfoques iniciales que deben desarrollarse con el manual educativo y las fuentes del proyecto.
- El planteamiento del problema debe contrastarse con las evidencias del diagnóstico territorial.
